# Metodología

Se recomienda un enfoque comparativo entre Ecuador y países de referencia, con análisis descriptivo, comparativo y econométrico básico.

## Modelo exploratorio

Se estima una regresión MCO del empleo sobre el índice de digitalización, efectos fijos por país y una tendencia temporal lineal. Los errores estándar se calculan con corrección robusta HC3.

Este modelo no establece causalidad. La muestra es pequeña, el índice de digitalización es un proxy y pueden persistir variables omitidas o tendencias comunes. Los resultados se presentan exclusivamente como evidencia descriptiva para orientar análisis posteriores.
